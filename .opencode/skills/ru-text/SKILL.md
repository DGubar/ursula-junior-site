# Russian Text For Ursula Course

Use this skill when editing Russian lesson text, page copy, explanations, task wording, or teacher-facing notes for the «Урсула: 3D-игры» course.

## Goals

- Make the text clear for students in grades 5-7.
- Preserve correct terminology for «Урсула» and ПРИМС.
- Prefer visual explanations over code-like wording.
- Keep mentor instructions direct and easy to follow.

## Checklist

- Replace abstract wording with concrete student actions.
- Explain ПРИМС through states, transitions, events, actions, icons, and screenshots.
- Avoid long sentences and overloaded paragraphs.
- Keep terms consistent: `Урсула`, `ПРИМС`, `состояние`, `переход`, `событие`, `действие`, `NPC`.
- Do not invent platform behavior; mark uncertain details as questions.
- Keep examples age-appropriate and practical.
- Use Russian typography consistently: «ёлочки», длинное тире, `т. д.`, `№`, no double spaces.

## Editing Style

- Lead with the action the student should perform.
- Use short headings and step-by-step structure.
- Prefer `что сделать` + `что должно получиться` over theory-first explanations.
- For teachers, add criteria for a good result when useful.
- For students, avoid internal implementation details unless they help complete the task.

## Before Publishing

- Check that screenshots and source materials are approved for publication.
- Do not expose files from `all docs for project/` unless the user approved moving selected assets into versioned folders.
- Verify links and page navigation after text edits.
